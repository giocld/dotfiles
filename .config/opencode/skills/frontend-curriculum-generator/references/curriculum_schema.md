# Curriculum Output Schema

The generated markdown file contains exactly five top-level sections, one per day.

## Per-day structure

```markdown
# Day {n}: {title}

## Learning objectives
- 3–5 bullet outcomes

## Theory summary
- Concise notes
- Code examples where helpful

## Code snippet
```html
<!-- annotated example -->
```

## Quiz
1. Question?
   - A) ...
   - B) ...
   - C) ...
   - D) ...
   - **Answer:** B

## Coding exercise
### Task
One-paragraph description of what to build.

### Starter code
```html
<!-- incomplete starter file -->
```

### Hints
- Hint 1
- Hint 2

### Solution
```html
<!-- reference solution -->
```
```

## Global front matter
The first lines of the file should be:

```markdown
# Frontend Curriculum — 5-Day Study Plan

Generated from class materials and WebPlatform Docs.
```
